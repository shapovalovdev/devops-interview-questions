# Establish a security platform risk model

How should a staff engineer align security investments across many platform teams?

## Answer guide

- Define assets, threats, business impact, control owners, and measurable risk outcomes with security and product leadership; use a common framework so teams compare risks consistently.
- Fund platform capabilities that remove repeated risky work, such as identity, secret delivery, secure defaults, logging, and recovery exercises. Publish adoption and exception metrics.
- Set risk-based service tiers and delivery expectations rather than one universal control set; revisit assumptions after incidents and architecture changes.
- A compliance checklist without ownership or evidence creates theater. Central mandates that ignore latency, cost, and developer workflow create bypasses; accept or escalate residual risk explicitly.
