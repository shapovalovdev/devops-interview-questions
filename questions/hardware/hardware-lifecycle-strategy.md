# Establish a server hardware lifecycle strategy

How would you set an organization-wide lifecycle strategy for production server hardware?

## Answer guide

- Define supported platform generations, ownership, warranty and end-of-support dates, security/firmware baselines, performance qualification, and a decommissioning process that includes data sanitization.
- Forecast demand and refresh lead time, maintain an approved exception register, and align the plan with application migration and procurement risk rather than refreshing solely by asset age.
- Make lifecycle health measurable: unsupported hardware, firmware compliance, spare coverage, failure rate, and migration progress. Without an accountable policy, fleets accumulate unpatchable systems and emergency refreshes.
