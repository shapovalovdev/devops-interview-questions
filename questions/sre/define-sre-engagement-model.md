# Define an SRE engagement model

Define an SRE engagement model is an SRE interview topic. Explain the mechanism, operational constraints, and failure modes.

## Answer guide

- Set transparent entry criteria based on service maturity, user impact, ownership, and operational load; describe what SRE and product teams each provide and retain.
- Use periodic reviews, explicit service objectives, capacity commitments, and an exit or transition path so the model scales beyond informal heroics.
- Do not create an exclusive reliability gate or silently absorb every team’s toil. An unclear engagement model produces dependency, resentment, and unreliable ownership.
