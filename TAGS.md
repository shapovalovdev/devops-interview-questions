# Tag vocabulary

Use lowercase kebab-case tags. Give every question one or more technology or concept tags and, where useful, a practice tag.

## Technologies and concepts

`ansible`, `aws`, `bash`, `cgroups`, `ci-cd`, `cloud`, `containers`, `dns`, `docker`, `git`, `github-actions`, `http`, `iam`, `images`, `infrastructure-as-code`, `kubernetes`, `linux`, `networking`, `observability`, `prometheus`, `security`, `tcp`, `terraform`, `tls`

## Practices

`automation`, `availability`, `debugging`, `delivery`, `deployment`, `incident-response`, `least-privilege`, `monitoring`, `reliability`, `rolling-update`, `supply-chain`, `troubleshooting`

Propose a new tag only when an existing tag cannot express the concept clearly.
