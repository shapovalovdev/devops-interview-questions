# CI/CD related materials

These resources complement the CI/CD Theme's Question-level references. They are
a curated starting point for pipeline mechanics and workflow syntax, GitOps
delivery with the Argo projects, progressive delivery and rollback, release
versioning, supply-chain provenance, and delivery metrics; check each one
against the runner platform, deployment target, and change-approval rules
actually in use before applying its advice.

## What to learn next

- Official documentation: [GitHub Actions documentation](https://docs.github.com/en/actions)
- Manual or specification: [SLSA v1.0 supply-chain specification](https://slsa.dev/spec/v1.0/about)
- Maintainer or personal blog: [Martin Fowler — Continuous Integration](https://martinfowler.com/articles/continuousIntegration.html)
- Technical blog: [Google Cloud — DevOps and SRE blog](https://cloud.google.com/blog/products/devops-sre)
- Hands-on guide: [Continuous Delivery — deployment pipeline patterns](https://continuousdelivery.com/implementing/patterns/)
