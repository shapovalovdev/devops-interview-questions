# Certified Kubernetes Application Developer (CKAD) coverage

This is a map of original practice Questions to the current official [CKAD curriculum](https://training.linuxfoundation.org/certification/certified-kubernetes-application-developer-ckad/). It is a learning index, not real exam content or a reproduction of confidential exam material. The official page stated Kubernetes v1.35 at review on 2026-08-06; check the current curriculum before studying.

Mapped Questions use the `ckad` certification tag and stay in their canonical Theme folders. Every Question has a full answer guide, primary-source metadata, and clearly marked complementary reading. A shared Question can appear in several certification paths; the tag does not imply an exact exam task.
