# KCNA coverage map

This map aligns original practice Questions with the current [Linux Foundation
KCNA domains](https://training.linuxfoundation.org/certification/kubernetes-cloud-native-associate/) and the
[CNCF curriculum](https://github.com/cncf/curriculum/tree/master/kcna). It is a study map, not a reproduction of
exam questions or confidential content.

| Official domain | Weight | Canonical Questions tagged `kcna` |
| --- | ---: | --- |
| Kubernetes Fundamentals | 44% | Pod specification basics; labels, selectors, and annotations; namespaces and resource scope; scheduling with affinity and taints; requests, limits, and QoS; container image and runtime; container lifecycle states |
| Container Orchestration | 28% | Service discovery; PersistentVolumeClaim lifecycle; NetworkPolicy enforcement; RBAC least privilege; secrets access and rotation; control-plane incident triage |
| Cloud Native Application Delivery | 16% | Deployment rollout and rollback; probe selection; ConfigMap delivery; CI, delivery, and deployment; Pod lifecycle and restarts |
| Cloud Native Architecture | 12% | Metrics, logs, and traces; SLI and SLO design; cloud-native principles and community collaboration |

Each mapped Question contains a full answer guide, primary-source metadata, and a clearly labeled complementary
technical blog post. Questions may also carry a more advanced certification tag where their scope overlaps.
